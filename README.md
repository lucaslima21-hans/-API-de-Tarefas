# -API-de-Tarefas

[0:00 - 0:20] Introdução e O Impacto
"Olá a todos. Hoje vou apresentar um caso real de vazamento massivo que começou por causa de uma única falha em um software. Em 2017, a Equifax, uma das maiores agências de análise de crédito do mundo, sofreu um ciberataque que expôs os dados confidenciais de 147 milhões de pessoas. Vazaram nomes, CPFs americanos (SSNs), datas de nascimento, endereços e até números de carteira de motorista."


[0:20 - 0:50] A Falha de Software (A Causa Raiz)
"Diferente do que muitos pensam, os hackers não precisaram criar uma tecnologia alienígena para invadir o sistema. Eles exploraram uma vulnerabilidade conhecida no Apache Struts (identificada como CVE-2017-5638). O Apache Struts é um framework de código aberto muito popular usado por programadores para criar aplicações web em Java. O bug nesse software permitia que criminosos injetassem comandos maliciosos diretamente nos servidores e executassem códigos remotamente."


[0:50 - 1:20] O Erro de Processo
"O ponto mais crítico é que a falha do software já tinha uma correção. A Apache Foundation lançou uma atualização de segurança em 7 de março de 2017. O governo americano notificou a Equifax no dia seguinte. No entanto, devido a falhas internas de comunicação e auditoria na própria empresa, o patch (a correção do programa) não foi aplicado nos sistemas afetados. Os criminosos encontraram a porta aberta e operaram silenciosamente lá dentro por mais de dois meses."

[1:20 - 1:50] As Consequências
"O impacto foi devastador. Além do roubo de identidade sofrido por milhões de cidadãos, o CEO da empresa foi forçado a renunciar. Em 2019, a Equifax fechou um acordo histórico e aceitou pagar até 700 milhões de dólares em multas e indenizações para encerrar os processos judiciais decorrentes do vazamento."


[1:50 - 2:00] Conclusão
"Este caso nos deixa uma lição clara: criar um software seguro é apenas metade do trabalho. A outra metade, tão vital quanto, é manter uma governança rígida de atualizações e correções. Um único pedaço de código desatualizado pode arruinar a reputação e as finanças de uma corporação inteira. Obrigado."
